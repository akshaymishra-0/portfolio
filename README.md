# Akshay Mishra - Portfolio

My personal portfolio website built with React, Vite, and Tailwind CSS. It showcases my projects, technical skills, internship experience, and academic background.

**Live Link:** [Portfolio](https://mathmagic-ai.vercel.app/)

---

## Tech Stack

- **Frontend:** React, Tailwind CSS, Lucide Icons
- **Tooling:** Vite
- **Deployment:** Vercel

---

## Features

- **Clean & Responsive UI:** Designed to work smoothly on mobile, tablet, and desktop screens.
- **Project Showcase:** Highlights my full-stack and machine learning projects with links to GitHub repos and live demos.
- **Experience & Education:** Details about my academic background, coursework, and my machine learning internship at SRSS Solutions.
- **Skills Overview:** Categorized breakdown of programming languages, web technologies, and tools.
- **Contact:** Direct links and a message form to get in touch easily.

---

## Getting Started

To run this project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/akshaymishra-0/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the dev server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
To create an optimized production build:
```bash
npm run build
```

